# Project Haykal - Android Studio Projects

Kumpulan project Android Studio oleh Haykal.

## 📁 Daftar Project:
1. **AplikasiPertama** - Aplikasi Android dasar / latihan pertama.
2. **IntentActivity** - Latihan penggunaan Intent dan Navigasi antar Activity.
3. **MenghitungNilaiMahasiswa** - Aplikasi kalkulasi nilai mahasiswa.
4. **MengirimDataAntarActivity** - Latihan mengirim dan menerima data antar Activity di Android.

## 🚀 Cara Menjalankan Project:
1. Clone repository ini:
   ```bash
   git clone https://github.com/haykalfaiz125-eng/projectHaykal.git
   ```
2. Buka **Android Studio**.
3. Pilih **Open** lalu pilih salah satu folder project di atas.
4. Sync Gradle dan Run aplikasi pada Emulator atau Perangkat fisik.
